# เดี๋ยวก็รู้ — เมืองปลายราง

เกมเว็บภาษาไทยแนว cozy pixel / mystery แบบเดินสำรวจเมืองเล็ก ๆ

## เล่น
เปิด `index.html` หรือใช้ GitHub Pages

## โลก
ผู้เล่นกลับมาอยู่ในเมืองที่เหมือนจำตัวเองได้ก่อนเจ้าตัวจะจำเมืองได้ มีร้านหนังสือ ไปรษณีย์ ร้านดอกไม้ ร้านซักผ้า และสถานีรถไฟ

เนื้อเรื่องจะค่อย ๆ เปิดผ่านของธรรมดา: เทปคาสเซ็ต หนังสือ จดหมาย ตั๋วรถไฟ รูปถ่าย และคนที่จำบางอย่างเกี่ยวกับผู้เล่นได้

## โทน
อบอุ่น แปลก เงียบ และเป็นบทกวีเล็กน้อย โดยไม่ใช่เกมสยองขวัญ
